# Kaamkar (کام کار)

Job board for Pakistan, Asia, and the Gulf — local office jobs, skilled trades, and overseas packages.

## Setup

```bash
npm install
npm run dev
```

TypeScript is a production dependency so `next.config.ts` loads without the “Installing TypeScript as it was not found” warning.

## Domain

Point www.kaamkar.com to the Vercel project after first deploy.
