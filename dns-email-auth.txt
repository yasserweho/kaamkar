# Email authentication for kaamkar.com

Add these at the domain DNS host. They cannot be set from the website code.

SPF (TXT on kaamkar.com):
v=spf1 include:_spf.google.com ~all

DMARC (TXT on _dmarc.kaamkar.com):
v=DMARC1; p=none; rua=mailto:hello@kaamkar.com

Change the SPF include if mail is not sent through Google.
